Bagaimana Fitur Auto-Connect Bekerja?

ESP32 menggunakan fitur bawaan WiFiMulti. Sistem akan memindai ketiga jaringan di atas secara otomatis. Jika jaringan utama (Slot 1) tiba-tiba mati atau di luar jangkauan, ESP32 akan langsung beralih ke jaringan cadangan (Slot 2 atau 3) yang paling kuat sinyalnya tanpa perlu restart alat.

Panduan Update Firmware ESP32 via Bluetooth

1

Ekspor File .bin dari Arduino IDE / PlatformIO

Setelah Anda menambahkan fitur baru pada kode program ESP32:

  • Di Arduino IDE: Klik menu Sketch → Export Compiled Binary (Ctrl+Alt+S). File .bin akan tersimpan di dalam folder proyek Anda.
  • Di PlatformIO: File firmware.bin otomatis dibuat di folder .pio/build/esp32/firmware.bin setelah di-compile.
  • Kirim atau simpan file .bin tersebut ke HP Android Anda (misal via WhatsApp / Google Drive / kabel).
2

Nyalakan Saklar Bluetooth ESP32

Buka halaman Firmware & BLE di aplikasi TeknoBro, lalu aktifkan toggle "Saklar Radio Bluetooth ESP32". ESP32 akan menyalakan pemancar BLE dengan nama TeknoBro-OTA.

3

Hubungkan Bluetooth HP ke ESP32

Pastikan Bluetooth di HP Anda sudah aktif. Klik tombol "Hubungkan Bluetooth" dan pilih perangkat TeknoBro-OTA pada jendela dialog yang muncul.

4

Pilih File .bin & Mulai Flash

Klik kolom "Pilih File Firmware (.bin)", pilih file binary yang sudah disiapkan di HP Anda, kemudian klik tombol biru "Mulai Flash Firmware".

5

Tunggu Hingga 100% Selesai

Aplikasi akan menampilkan animasi transfer data live. Setelah mencapai 100%, ESP32 akan otomatis restart dalam hitungan 2-3 detik dan menjalankan firmware baru dengan semua fitur terbaru!

Tips Hemat Daya: Setelah proses update selesai, Anda dapat mematikan kembali saklar Bluetooth ESP32 agar daya listrik hemat dan sinyal WiFi semakin optimal.
